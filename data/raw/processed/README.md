# MuleGuard Dataset

## Source
IBM AMLSim synthetic transaction data.

## Purpose
Used for:
- AML pattern detection
- Money-mule analysis
- Graph analysis
- ML experimentation

## Data Layers

raw/
- Original downloaded dataset
- Never modify these files

processed/
- Cleaned and transformed data
- Used by MuleGuard services

## Important
Raw dataset files are treated as source data and should remain unchanged.
