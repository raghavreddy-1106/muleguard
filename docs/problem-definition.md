# MuleGuard

## Problem
Criminal networks can use multiple mule accounts to split,
move, and consolidate illicit funds through apparently normal
transactions. This makes individual suspicious transactions
difficult to identify.

## Objective
Build a platform that identifies suspicious transactions,
accounts, and transaction networks using AML rules, machine
learning, and graph analysis.

## Primary Users
- AML Analyst
- Compliance Officer
- Administrator

## Core Capabilities
1. Transaction ingestion
2. AML rule detection
3. ML-based risk prediction
4. Money-mule/network detection
5. Risk scoring and explanation
6. Analyst investigation dashboard
7. Authentication and role-based access
8. Audit logging

## Expected Output
For a transaction/account/network, the system should provide:
- Risk score
- Risk level
- Detection reasons
- Related suspicious accounts
- Investigation status
- Audit history
